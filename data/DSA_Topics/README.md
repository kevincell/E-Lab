# 📚 Data Structures & Algorithms Question Bank

A structured, comprehensive question bank containing **300 algorithmic problems** (20 topics × 15 problems each), directly referencing the problem categorization from [SamirPaulb/DSAlgo](https://github.com/SamirPaulb/DSAlgo).

Each problem includes:
- **Difficulty Level & Tags**
- **Detailed Problem Description**
- **Input / Output Format**
- **2 to 3 Concrete Sample Test Cases with Step-by-Step Explanations**
- **Constraints & Edge Cases**
- **Time & Space Complexity Targets**
